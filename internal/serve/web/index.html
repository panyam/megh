    What these keys allow

      Paste your control-plane note, or just the lines to add. Each one adds to or replaces that key for this tab, and a key the server holds wins over the tab's. Keys stay in this tab's session storage and go to the server only as headers on each request; closing the tab forgets them.

      Boxes

      No boxes.

        Launch

        Machines that meet these minimums where the chosen volume is. Pick one, or launch with none picked to get the cheapest.

        Volumes

        A box starts on its volume's provider, in its data center. Volumes bill monthly whether or not a box uses them, at that provider's volume price.

          Regions

          Probing rents a real box in each data center for about a second and terminates it, a fraction of a cent each. Place probes until one rents, then creates a volume there.

          This provider publishes which locations sell each size, so there is nothing to probe: these are the locations selling the minimums chosen under Launch, cheapest first, with the type a box would get.
